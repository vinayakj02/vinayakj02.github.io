community events

Community events and conferences I've attended.

FOSS India 2023

IndiaFOSS is an annual Free and Open Source Software (FOSS) conference organised by the FOSS United community. Learnt about a lot of cool FOSS initiatives by Zerodha (Kailash) and others.

KubeDay

In 2023, the primary CNCF-supported events in Bangalore focused on community-driven gatherings. Key events included KubeDay India (Dec 8), Kubernetes Community Days (KCD) Bengaluru (June 2), and various specialized meetups focusing on Nephio, security, and sustainability. Interacted and learnt about container security and monitoring at scale.

Mumbai SANOG 2024

South Asian Network Operators' Group conference in Mumbai. Participated in a DNS workshop.

API Day Coastal Karnataka

Volunteered at API Day Coastal Karnataka (300+ attendees, 5 speakers), organized by COSH NITK with Postman and IRIS, NITK. Parth Mittal's post about the event on LinkedIn.
