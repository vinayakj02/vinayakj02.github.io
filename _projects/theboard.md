A simple yet powerful real-time whiteboard application that enables multiple users to collaborate on drawing and designing together in shared rooms using websockets.

## Features
* Real-time collaborative whiteboard
* Multiple rooms for different projects or teams
* Live synchronization across all connected clients
* Simple and intuitive drawing interface
* WebSocket-based communication for instant updates

## Tech Stack
* **Frontend**: JavaScript, HTML
* **Backend**: Python
* **Communication**: WebSockets for real-time updates

## How It Works
1. Create or join a room
2. Start drawing on the board
3. All collaborators in the same room see your strokes in real-time
4. Perfect for brainstorming sessions, design collaboration, or remote teaching

## Use Cases
* Team brainstorming sessions
* Remote collaboration on designs
* Interactive teaching and workshops
* Real-time sketching and planning
